# MozaProof

MozaProofは、PNG画像にモザイクをかけたり、指定した色で塗りつぶしたりできるWindows向けアプリです。画像の検出から保存まで、すべて端末内で処理します。

## 必要環境

- Windows 10 / 11
- Python 3.11以降
- PySide6
- Pillow
- ONNX Runtime
- OpenCV（headless版）

対応する入出力形式は **PNGのみ** です。

## セットアップ

PowerShellでプロジェクトフォルダを開き、仮想環境を作成します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 起動

```powershell
python main.py
```

## 使い方

1. 「画像を開く」を押すか、PNGをキャンバスへドラッグ＆ドロップします。
   初期設定では、完全ローカルのアニメ対応YOLOとMobileSAMが性器候補を検出し、輪郭に沿ったモザイクマスクを自動追加します。
2. モザイクブラシ、塗りつぶしブラシ、モザイクを解除を選んで画像上をドラッグします。
3. ホイールでズームし、`Space`+ドラッグまたは中ボタンで表示位置を動かします。
4. 比較ボタンを押している間は、加工前の画像を確認できます。
5. 「名前を付けて保存」から別名のPNGとして保存します。

右側の「画像情報」には、ピクセル寸法、長辺、元PNG容量、透明度、pixiv推奨モザイクサイズを表示します。編集表示には長辺最大1600pxの軽量キャッシュを使い、保存時は元解像度で処理します。

`Ctrl+Z`でUndo、`Ctrl+Y`でRedoできます。「モザイクを解除」は元画像ではなく、モザイクと塗りつぶしの加工範囲を消します。

自動検出結果は通常の加工マスクなので、「モザイクを解除」で余分な範囲を削り、モザイクブラシで見逃しを追加できます。小さな候補は周囲を拡大して輪郭を求めます。輪郭に加える余白は、候補の大きさに応じて1〜4pxです。自動検出には誤検出・見逃しがあるため、保存前に必ず目視確認してください。モデルはアプリへ同梱され、画像や判定結果を外部へ送信しません。

自動検出にはMobileSAM（Apache-2.0）とHotscreen YOLO11 real/anime detector（AGPL-3.0）を使用します。ライセンス全文とモデル出典は`models`フォルダへ同梱しています。特にexeを第三者へ配布する場合は、AGPL-3.0の条件を確認してください。

## pixiv対応プリセット

起動後の初期ツールはモザイクブラシです。画像を読み込むと次の値を設定します。

- モザイクブロック: `max(4, round(画像の長辺 / 100))` pxを基準に、画面では`1`〜`50` pxの範囲で選択
- ブラシ: `45` px（最大 `100` px）
- マスク膨張: OFF。ONにすると`1`〜`10` pxの範囲で選択

「pixiv推奨値に戻す」でいつでも初期値へ戻せます。モザイクは縮小後に最近傍で拡大する不可逆なピクセル化であり、ぼかしや半透明表示ではありません。

## 保存とメタデータ

右側の「PNG保存設定」で、圧縮レベルとメタデータの扱いを選べます。次回の起動時にも前回の設定を使います。

- **圧縮レベル**は0〜9で、初期値は速度を優先する1です。0は無圧縮、9は容量を抑えたいときに使います。どの値でも画像の画素と透明度は同じです。
- **メタデータ**は初期設定で削除します。「保持する」を選ぶと、生成プロンプトやワークフローなどのテキスト、EXIF、ICCプロファイル、解像度などを保存します。引き継げない付加情報がある場合は、保存前にその種類を表示します。

- 初期ファイル名: `元ファイル名_mozaproof.png`
- 元画像と同じパスへの保存は禁止
- 実際に符号化したPNGが32 MiBを超える場合は保存前に警告
- 一時ファイルを使う原子的保存を行い、失敗時も一時ファイルを削除

## Windows用exeのビルド

PyInstallerは`requirements.txt`に含まれています。モデルと必要データを同梱するため、仮想環境を有効にして同梱設定済みのspecファイルからビルドします。

```powershell
pyinstaller MozaProof.spec
```

生成物は`dist\MozaProof\MozaProof.exe`です。モデルファイルを含む`_internal`フォルダも必要なので、フォルダ単位で使用・配布してください。

## 注意事項

本アプリはpixivを含む各投稿サービスでの投稿可否を保証するものではありません。加工結果を十分に拡大して確認し、投稿前の最終判断はユーザー自身で行ってください。

## 追記: モザイク倍率

ブラシ設定に「モザイク倍率」を追加しています。画像読み込み時は「標準」で、pixiv推奨ブロックサイズをそのまま使います。必要に応じて「2/3」または「1/2」を選ぶと、推奨値を基準にブロックサイズが小さくなります。ブロックサイズ欄へ直接数値入力することもできます。
