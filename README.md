# Pixiv Safe Mosaic

PNG画像へモザイクまたは不透明な塗りつぶしを行い、入力画像由来のPNGメタデータを除去して保存する、Windows優先のローカルデスクトップアプリです。画像処理はすべて端末内で完結し、インターネット通信を行いません。

## 必要環境

- Windows 10 / 11
- Python 3.11以降
- PySide6
- Pillow
- ONNX Runtime
- OpenCV（headless版）

対応する入出力形式は **PNGのみ** です。

## セットアップ

PowerShellでプロジェクトフォルダを開き、仮想環境を作成します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 起動

```powershell
python main.py
```

## 使い方

1. 「画像を開く」を押すか、PNGをキャンバスへドラッグ＆ドロップします。
   初期設定では、完全ローカルのアニメ対応YOLOとMobileSAMが性器候補を検出し、輪郭に沿ったモザイクマスクを自動追加します。
2. モザイクブラシ、塗りつぶしブラシ、消しゴムを選んで画像上をドラッグします。
3. ホイールでズームし、中ボタンまたは `Space`+ドラッグで表示位置を動かします。
4. 比較ボタンを押している間は、加工前の画像を確認できます。
5. 「名前を付けて保存」から別名のPNGとして保存します。

右側の「画像情報」には、ピクセル寸法、長辺、元PNG容量、透明度、pixiv推奨モザイクサイズを表示します。編集表示には長辺最大1600pxの軽量キャッシュを使い、保存時は元解像度で処理します。

`Ctrl+Z`でUndo、`Ctrl+Y`でRedoできます。消しゴムは元画像ではなく、モザイクと塗りつぶしの加工範囲を消します。

自動検出結果は通常の加工マスクなので、消しゴムで余分な範囲を削り、モザイクブラシで見逃しを追加できます。自動検出には誤検出・見逃しがあるため、保存前に必ず目視確認してください。モデルはアプリへ同梱され、画像や判定結果を外部へ送信しません。

自動検出にはMobileSAM（Apache-2.0）とHotscreen YOLO11 real/anime detector（AGPL-3.0）を使用します。ライセンス全文とモデル出典は`models`フォルダへ同梱しています。特にexeを第三者へ配布する場合は、AGPL-3.0の条件を確認してください。

## pixiv対応プリセット

起動後の初期ツールはモザイクブラシです。画像を読み込むと次の値を設定します。

- モザイクブロック: `max(4, round(画像の長辺 / 100))` px
- ブラシ: `30` px
- マスクを1ブロック分膨張: OFF

「pixiv推奨値に戻す」でいつでも初期値へ戻せます。モザイクは縮小後に最近傍で拡大する不可逆なピクセル化であり、ぼかしや半透明表示ではありません。

## 保存とメタデータ

保存時は元解像度の画像へ加工を再適用し、新しいRGBA画像としてPNGを生成します。入力PNGのtextual metadata、EXIF、ICCプロファイルなどは引き継ぎません。元画像のアルファチャンネルは維持します。

- 初期ファイル名: `元ファイル名_pixiv_safe.png`
- 元画像と同じパスへの保存は禁止
- 実際に符号化したPNGが32 MiBを超える場合は保存前に警告
- 一時ファイルを使う原子的保存を行い、失敗時も一時ファイルを削除

## Windows用exeのビルド

PyInstallerは`requirements.txt`に含まれています。モデルと必要データを同梱するため、仮想環境を有効にして同梱設定済みのspecファイルからビルドします。

```powershell
pyinstaller PixivSafeMosaic.spec
```

生成物は`dist\PixivSafeMosaic\PixivSafeMosaic.exe`です。モデルファイルを含む`_internal`フォルダも必要なので、フォルダ単位で使用・配布してください。

## 注意事項

本アプリはpixivを含む各投稿サービスでの投稿可否を保証するものではありません。加工結果を十分に拡大して確認し、投稿前の最終判断はユーザー自身で行ってください。
